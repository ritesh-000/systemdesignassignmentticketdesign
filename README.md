# Movie Ticket Booking System

A C++ based Movie Ticket Booking System designed using Object-Oriented Programming and System Design principles.

## 📌 Project Overview

This project simulates a movie ticket booking system where users can view available movies, select shows and seats, make bookings, and manage their tickets.

The project is divided into multiple modules/classes to demonstrate concepts such as:

- Object-Oriented Programming
- Class Design
- Encapsulation
- Composition
- Relationships between classes
- Modular Design
- Service-based architecture
### Compile

g++ -std=c++17 -Wall main.cpp -o booking_system.exe
